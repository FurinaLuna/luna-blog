# luna-blog 视觉与交互规范

> 设计原则：**长相沿用原型，代码全部重写。**
> 前台还原原 `vue3-blog/blog-v3` 的外观与交互（蓝色主色、全屏天空首页、卡片化内容、波浪过渡、
> 常驻音乐播放器）；后台还原原 `vue3-blog/blog-v3-admin`（pure-admin 观感：深色侧栏 + 标签页 +
> 表格化内容页）。技术栈是新的一套（Vue 3.5 / Vite 8 / TS 7 / Pinia 4 / Tailwind 4 / Element Plus 2.14），
> 只换实现不换长相，便于从旧站平滑迁移。
>
> 逐像素的考古数据（原始 SCSS 变量、尺寸、keyframe、图标清单）见：
> - [`docs/PROTOTYPE-web.md`](PROTOTYPE-web.md) —— 前台 600 行原型档案
> - [`docs/PROTOTYPE-admin.md`](PROTOTYPE-admin.md) —— 后台 357 行原型档案
>
> 本文是实现侧的落地约定，与代码一一对应。

## 1. 前台（blog-web）

### 1.1 全局 Token

定义位置：`blog-web/src/styles/index.css`（Tailwind 4 CSS-first，`@theme` + `:root`/`html.dark` 双套变量）。

配色分「填充」与「文字」两条线：填充用 `--primary`（浅色 `#1d7ab5` / 深色 `#4db3f7`），文字和图标用 `--primary-ink`（浅色 `#17699c` / 深色 `#7cc8ff`），填充上的文字用 `--on-primary`（浅色白 / 深色深墨 `#06121c`）。这样白底链接对比度 5.4:1、深色按钮文字 8.2:1，都不再是「浅蓝字糊在白底上」。

| 变量 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--primary` | `#1d7ab5` | `#4db3f7` | 填充主色：按钮、标签激活、进度 |
| `--primary-ink` | `#17699c` | `#7cc8ff` | 文字/图标主色：链接、激活态文字 |
| `--on-primary` | `#fff` | `#06121c` | 填充色上的文字 |
| `--bg` | `#f4f7fb` | `#10151b` | 页面底色（冷白 / 深海军蓝黑） |
| `--card-bg` | `#ffffff` | `#171d26` | 卡片 |
| `--bg-soft` | `#eef3f9` | `#1f2732` | 次级底（输入框、hover 行、标签底） |
| `--text` | `#1f2a37` | `#e2e8f1` | 正文（白底 14.5:1） |
| `--text-2` | `#4a5666` | `#aab6c6` | 次级正文（白底 7.5:1） |
| `--meta-color` | `#6b7684` | `#8593a6` | 日期、阅读量等元信息（4.6:1 以上） |
| `--border` | `#e4ebf4` | `#2a3441` | 分割线、边框 |
| `--accent` | `#e2534a` | `#ff7a6e` | 置顶/强调红 |
| `--shadow` | `0 1px 2px rgba(15,23,42,.04), 0 10px 24px -14px rgba(15,23,42,.18)` | 更深、更柔的黑色阴影 | 卡片阴影 |
| `--code-bg` / `--code-head-bg` | `#f6f8fb` / `#eceff5` | `#121821` / `#182029` | 代码块底 / 头部 |
| `--cover-grad-1..4` | 低饱和蓝 | 深蓝 | 无封面时的占位渐变（按标题哈希取一） |

深色主题不再是纯中性灰，而是与品牌蓝同族的海军蓝石板色（`#10151b` → `#171d26` → `#1f2732` 三层），层级靠亮度差而不是边框线；后台 `blog-admin` 的深色也同步到同一色族（页面 `#0d131a`、卡片 `#151c26`、表头 `#1a222c`）。

关键约定：

- **根字号 14px**（`html { font-size: 14px }`）。原型全站 rem 按 14px 计算，漏设会整体放大 14%。
- **字体**：`"HarmonyOS Sans SC", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`；
  数字与代码用等宽字体。
- **圆角**：卡片 8px、按钮/标签 6px、头像与唱片圆形。
- **过渡**：统一 `0.3s ease`；卡片 hover 上浮 4px + 阴影增强。

### 1.2 页面骨架

```

AppFooter（运行时长走秒（X 天 07 小时 29 分 16 秒）/ 总访问量与总访客数 / 版权 / ICP / 技术栈彩色徽章）
```

- 导航项（全部平铺，**无下拉菜单**）：搜索、主页、时间轴、分类、标签、相册、说说、友链、留言、资源、关于、主题切换；
  「分类」「标签」直接进各自的总览页（不展开列表）。

### 1.3 首页

1. **欢迎区（100vh）**：默认天空渐变 + 云层纹理（`src/assets/img/clouds.png` 叠加，纯 CSS 保证离线可看）；
   后台「站点配置 → 页面横幅」给首页传了图时，改用该图片铺满 + 深色渐变遮罩（保证白色站名可读）。
   → 居中站名 + 打字机副标题（循环打字，末尾光标闪烁）→ 向下箭头。
2. **波浪过渡**：`PrototypeWaves.vue` 白浪 SVG 压住欢迎区底部。
3. **内容区（浅灰底，`max-width:1080px`，两栏）**：
   - 左栏（`sm=18`）文章列表，每页 **5 篇**，每篇一张**左右交替的横向卡片**（桌面 16rem 高，封面 40% 宽、
     信息区 55%：标题 1.6rem/600 → meta 行（置顶 / 发表于 / 更新于 / 分类 / 标签 / 点赞 / 阅读，`|` 分隔）→
     3 行摘要）；手机改为纵向（封面 100%×14rem）。hover：卡片上浮 3px + 封面 `scale(1.1)`。
   - 右栏（`sm=6`，手机隐藏）自上而下：**个人资料卡**（横幅 8.6rem 可点击进关于页 + 头像 60px 上浮旋转 + 站名 →
     横幅图取 `siteConfig.profileBanner`，为空时回退 `pageBanners.home`，再为空用内置渐变；头像与站名 `z-index` 高于横幅，任何情况下不被横幅遮盖 →
     一句话 → **文章/分类/标签三列统计，各自可点**：文章→`/archives`、分类→`/categories`、标签→`/tags` →
     全宽主色按钮（粉丝专页：优先 `socialLinks` 里的 Gitee、其次 GitHub，文案 `My Gitee` / `My GitHub`，
     都没有时退化为「关于我」）→ 居中社交图标行（32px 一行最多 5 个，多出的折叠成「+N」链到关于页，主按钮那个链接不重复出现）→ **推荐阅读**（只显示后台勾了「推荐」的文章，最多 8 条：50×40 缩略图 + 标题 + 日期；没有推荐时整块卡片隐藏）→
     **标签云**（稳定随机浅色胶囊，点击跳 `/tag/:id`；标签多时卡片内限高 10.5rem 竖向滚动）→ **网站资讯**（文章数 / 运行天数 / 总访问量 / 总访客数 / 评论数；访问量来自 `POST /api/visit` 上报的页面浏览，访客数按 IP 哈希去重；历史访问数据以 `visit` 表行形式导入（旧站 3405 次 / 1893 人），页脚与卡片同一口径）。
   - 分页沿用 `Pagination`（`pager-count=5`）；加载时渲染 5 张交替骨架。

### 1.4 其余页面

统一「暗色天空 banner + 白色波浪 + 浅灰内容区 + 白卡」骨架，页面头部左侧是大标题与描述。
banner 默认是 CSS 天空 + 云层；后台「站点配置 → 页面横幅」可给下列 15 个页面之一单独上传横幅图（分类总览 / 标签总览未单独上传时回退到分类详情 / 标签详情的图）
（键：`home, archives, categories, category, tags, tag, article, talks, albums, album, resources, friends, message, about, search`），
有图时 `PageHeader` 自动按路由首段取图，未配置则回退内置渐变。自定义横幅用 `background-size: cover` 铺满整条横幅、
`background-position: center top` 纵向贴顶（保证画面主体的上半部分不被切掉），再叠一层 rgba(4,16,28,.38) 暗色遮罩保证白色标题可读。
内页 banner 高 36rem（关于页 41rem、手机 25rem）；底部白浪高 6rem（手机 4.6rem），
与首页 hero 同高（原为 4rem），图片横幅下波浪起伏更明显。

| 页面 | 关键结构 |
| --- | --- |
| 文章详情 `/article/:id` | banner 含标题/meta/标签 → 白卡 Markdown 正文（代码高亮、行号、复制）→ 右侧 sticky 目录（`ArticleToc.vue` 自绘：只取 h2–h4、按层级缩进、可滚动并自动跟随当前小节、激活项主色条 + 淡底）→ 点赞 → 上下篇 → 二级评论气泡列表 |

| 分类总览 `/categories` | 沿用原站「分类」页：居中白卡，首行 `分类 - N`，其下彩色分类云（按 id 稳定哈希取字号 0.95–2.2rem 与色相），点击进对应分类 |

| 搜索 `/search` | 大输入框 + 结果卡片列表 |

| 留言板 `/message` | 沿用原站：默认进入弹幕模式，标题可点击切换「弹幕 / 卡片」（选择写入 localStorage）→ 卡片模式为双列彩色面板（22rem 高：头像 + 昵称胶囊 + `#序号`、15rem 可滚动正文、底部时间胶囊与点赞），无限滚动；弹幕模式为夜空 + 20 颗流星整屏铺满（16:9 视口内无滚动、隐藏页脚，弹幕从顶栏下方起播），中央标题切回卡片，hover 发布键展开胶囊输入；发布走 480px 弹窗（昵称 / 内容 / 弹幕颜色） |

Markdown 代码块（文章详情与关于页）统一为一张卡片：头部 2.5rem（mac 三圆点 + 语言标签 + 「复制代码」胶囊），代码区行号右对齐并弱化为灰色、等宽字体 1rem / 字重 600 / 行高 1.78；`--code-bg` / `--code-head-bg` / `--code-border` /`--code-ln` 四组变量分别给明暗两套配色；预览关闭自动折叠（`:code-foldable="false"`），避免长代码块只剩一条头部栏。
| 404 | 插画 + 「这一页走丢了」+ 3 秒自动回首页 |

### 1.5 交互与状态

- 所有列表：加载骨架屏 → 空态（`EmptyState`）→ 错误提示，均不白屏。
- 访客评论：昵称 + 邮箱必填，提交后提示「已提交，待站长审核」；列表只显示已审核内容。
- 点赞：同 IP 幂等（重复点击不重复计数），乐观更新后以接口返回计数为准。
- 音乐播放器：`/wapi` 3 秒超时或返回空歌单时**整体不渲染**，不出现空壳按钮。
- 深色模式：跟随系统 / 手动浅色 / 手动深色三态，持久化到 localStorage，`html.dark` 驱动变量。

## 3. 前端工程约定（两端通用）

- **目录按 feature 组织**：`src/api`（接口层，与 `docs/API.md` 一一对应）、`src/stores`（auth/site/theme）、
  `src/components`（可复用）、`src/views|pages`（路由页）、`src/styles`（全局样式与 token）。
- **类型严格**：`tsconfig` strict + `noUnusedLocals`，禁止 `any`；接口响应在 `api/types.ts` 定义。
- **构建前必过类型检查**：
  - blog-web：`npx tsc --noEmit` + `node scripts/check-vue.cjs --noEmit` + `vite build`
  - blog-admin：`node scripts/check.cjs`（TS7 管 `.ts`、TS6+vue-tsc 管 `.vue`）+ `vite build`
- **Element Plus 与 Tailwind 4 共存**：EP 样式按 `@layer` 顺序导入，Tailwind preflight 不得重置 EP
  组件；改样式后要实际点开 `el-select`/`el-dialog`/`el-table`/`el-pagination` 验证。
- **素材来源**：`clouds.png`、页面图标 SVG、后台登录插画与状态插画来自原型项目，随仓库提供；
  不引用任何外链图片，保证离线可用。
- **社交图标**：`blog-web/src/components/common/social-icons.ts` 内联了 14 套 24×24 单色品牌图标
  （GitHub / Gitee / 哔哩哔哩 / 微信 / QQ / 微博 / 知乎 / 掘金 / 抖音 / X / Telegram / YouTube / 网易云音乐 / RSS），
  用 `currentColor` 填充，不依赖图标 CDN；`SocialLinks.vue` 按 `icon` 或 `name` 里的关键字自动匹配
  （中英文都认，如「微信」「weixin」「bilibili」「码云」），匹配不到时退回链接图标，邮箱渲染信封图标。
  后台「站点配置 → 社交链接」最多可配 16 条；首页资料卡一行最多铺 5 个，多出的折叠成「+N」链到关于页。
